# Deckly — Sistema Desktop

O Deckly Desktop é a versão desktop do projeto Deckly, desenvolvido em C# com Windows Forms.

## Funcionalidades

- Gerenciamento de produtos.
- Gerenciamento de clientes.
- Gerenciamento de funcionários e cargos.
- Acesso às funcionalidades por meio de uma interface desktop.
- Relatórios do sistema.

## Tecnologias utilizadas

- C#
- Windows Forms
- MySQL
- Visual Studio

## Banco de dados

O sistema utiliza o banco de dados do projeto Deckly. Configure a conexão com o banco de dados no ambiente local antes de executar a aplicação.

## Como executar

1. Abra o arquivo `SistemaDeckly.sln` no Visual Studio.
2. Restaure os pacotes necessários.
3. Configure a conexão com o banco de dados.
4. Compile e execute o projeto.

## Observação

Este projeto faz parte do ecossistema Deckly, que também possui uma versão web.
